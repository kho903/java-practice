
# 소수 판별(Prime Number)

## 1. 소수란?

1보다 큰 자연수 중 약수가 1과 자기 자신뿐인 수

- 1은 소수가 아님
- 2는 유일한 짝수 소수
- 예: 2, 3, 5, 7, 11, 13, 17

## 2. 소수 판별 알고리즘

N이 소수인지 확인하기 위해 약수의 존재 여부를 검사하는 알고리즘

- 기본 방식: 2부터 N-1까지 검사
- 최적화 방식: 2부터 √N까지만 검사
- N이 합성수라면 √N 이하의 약수가 반드시 존재함
- 나누어떨어지는 약수가 존재하면 소수가 아님

## 3. Java 구현

```java
boolean isPrime = true;

if (n <= 1) {
    isPrime = false;
} else {
    int root = (int) Math.sqrt(n);

    for (int i = 2; i <= root; i++) {
        if (n % i == 0) {
            isPrime = false;
            break;
        }
    }
}

System.out.println(isPrime ? "Prime" : "Not Prime");
```

- `Math.sqrt(n)`으로 제곱근 계산
- `(int)` 형변환으로 소수 부분 제거
- 나누어떨어지는 수가 발견되면 `break`로 종료
- 제곱근까지 검사할 때는 `<=` 조건 사용

## 4. 시간 및 공간 복잡도

| 방식 | 시간 복잡도 |
|---|---|
| 모든 수 검사 | O(N) |
| 제곱근까지만 검사 | O(√N) |

- 추가 공간 복잡도: O(1)
- 단일 정수의 소수 판별에 적합

## 5. 핵심 요약

- 소수는 1보다 크고 약수가 1과 자기 자신뿐인 수
- √N 이하의 약수만 확인해도 소수 판별 가능
- 하나의 정수 판별에는 O(√N) 알고리즘 활용
- 여러 정수의 소수를 한꺼번에 구할 때는 에라토스테네스의 체 활용 가능
