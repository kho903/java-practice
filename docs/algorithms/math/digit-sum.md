
# 각 자릿수의 합(Digit Sum)

## 1. 핵심 개념

정수의 각 자릿수를 분리하여 합산하는 알고리즘

- `n % 10` : 마지막 자릿수 추출
- `n / 10` : 마지막 자릿수 제거
- `while` 반복문으로 모든 자릿수 처리

## 2. Java 구현

```java
int sum = 0;

while (n > 0) {
    sum += n % 10;
    n /= 10;
}
```

## 3. 시간 및 공간 복잡도

- 시간 복잡도 : O(log N)
- 공간 복잡도 : O(1)
- 반복마다 N을 10으로 나누므로 자릿수에 비례하여 실행

## 4. 핵심 요약

- `% 10`과 `/ 10`을 조합하여 숫자의 각 자릿수 처리 가능
- 자릿수 합, 숫자 뒤집기, 자릿수 개수 세기 등에 응용 가능
