# 에라토스테네스의 체(Sieve of Eratosthenes)

## 1. 핵심 개념

2부터 N까지 소수의 배수를 제거하여 모든 소수를 찾는 알고리즘

- 정수 하나가 아닌 여러 정수의 소수 판별에 적합
- 소수가 아닌 숫자를 배열에 표시
- 2부터 √N까지만 배수 제거 작업 수행

## 2. 동작 원리

- `boolean[]` 배열을 사용하여 합성수 표시
- Java의 boolean 배열은 기본값이 `false`
- 소수 i에 대해 i * i부터 배수 제거
- 이미 합성수인 i는 건너뛰기
- 마지막까지 제거되지 않은 2 이상의 숫자가 소수

- `i * i`보다 작은 배수는 이전 단계에서 이미 처리됨
- `j += i`로 i의 배수만 순회
- 0과 1은 소수가 아니므로 2부터 출력

## 4. 시간 및 공간 복잡도

| 구분 | 복잡도            |
|----|----------------|
| 시간 | O(N log log N) |
| 공간 | O(N)           |

- `boolean[n + 1]` 배열 사용
- 많은 수의 소수를 구할 때 효율적

## 5. 소수 판별과 비교

| 구분     | 소수 판별     | 에라토스테네스의 체     |
|--------|-----------|----------------|
| 목적     | 하나의 정수 판별 | N 이하의 모든 소수 탐색 |
| 시간 복잡도 | O(√N)     | O(N log log N) |
| 공간 복잡도 | O(1)      | O(N)           |

## 6. 핵심 요약

- 하나의 정수 판별은 √N까지 검사
- 여러 정수의 소수 판별은 에라토스테네스의 체 활용
- 소수의 배수를 i * i부터 제거하여 중복 연산 최소화
